Forward ``transform(event)`` unless it is ``None``.

<PySourceCode >

```python
def record(self, event: Event) -> None:
    """Forward ``transform(event)`` unless it is ``None``.

    Args:
        event: The event to transform.
    """
    mapped_event = self.transform(event)
    if mapped_event is not None:
        self.inner.record(mapped_event)
```
