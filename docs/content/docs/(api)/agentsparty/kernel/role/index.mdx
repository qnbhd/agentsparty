<PySourceCode >

```python
def roles(*names: str) -> tuple[Role, ...]:
    """Build several :class:`Role` objects, one per *name*.

    Args:
        *names: Role names, in the order they appear in a protocol.
    """
    return tuple(Role(name) for name in names)
```
